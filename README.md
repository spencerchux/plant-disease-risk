# 🌱 Plant Disease Risk Prediction

## 📌 Project Overview

This project uses machine learning and data analysis to predict plant disease risk based on environmental and agricultural conditions.

The objective is to identify factors associated with plant disease and build a predictive model that can support early disease detection and agricultural decision-making.

## 🎯 Objectives

- Explore and understand the plant disease dataset
- Clean and prepare the data for analysis
- Perform exploratory data analysis (EDA)
- Identify important factors associated with plant disease risk
- Build a machine learning classification model
- Evaluate the performance of the model
- Generate practical agricultural recommendations

## 🤖 Machine Learning

The project applies classification techniques to predict plant disease risk from the available environmental and agricultural features.

Model performance is evaluated using appropriate classification metrics to determine how effectively disease-risk cases can be identified.


## 📊 Key Findings

- LightGBM was the best-performing machine learning model.
- The final LightGBM model achieved a test accuracy of **86.64%**.
- The model achieved a **ROC-AUC score of 0.795**.
- Soil pH and temperature were among the most influential variables for predicting plant disease risk.
- Rainfall and humidity also contributed to disease-risk prediction.

## 💡 Agricultural Recommendations

- Monitor environmental conditions associated with increased disease risk.
- Use predictive analytics to support earlier intervention.
- Prioritize preventive measures when conditions indicate elevated disease risk.
- Continue collecting high-quality agricultural data to improve future predictions.
- Use machine learning predictions alongside agricultural expertise rather than as a replacement for field assessment.
